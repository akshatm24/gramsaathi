PROTOTYPE V2

Real workflow. Sandbox services.

This prototype uses a separate portal with real form inputs, server validation, document upload, stored cases, correction requests and receipts. The agent uses a deterministic service adapter, not an LLM or general-purpose browser agent.

Working features

Step-by-step English/Hindi questions, speech input where supported, text document extraction with confirmation, persistent cases, manual sandbox login, actual portal field filling, consented backend submission, prerequisite tracking, and a reviewer simulator.

Sandbox boundaries

All government services, eligibility rules, login, approvals, certificates and DigiLocker retrieval are demonstration-only. The fictional Maharashtra pilot requires an income certificate for its sample farm-support service; this is not an official scheme rule.

Data and access

Only upload fictional documents. Case details and files are stored on the prototype server. Your browser keeps a private case key; a recovery file contains that key. Anyone with that file can access the case. Use Delete case to remove server data. No real Aadhaar numbers or passwords.

Image/PDF OCR and a connected LLM are not enabled. Plain-text sample documents can be extracted. Speech may be processed by your browser's speech provider. Official APIs and a protected real login environment require separate integration.
