# GramSaathi — presenter script

## Opening (20 seconds)
“Digital services are online, but the work of using them still falls on the citizen. GramSaathi explores a different experience: explain your need, approve a plan, and let a service agent perform supported steps while you remain in control.”

## Demonstration (3–5 minutes)
Use the agricultural-support journey with sample details. Show the missing-certificate prerequisite, document extraction and upload consent, manual login, actual portal filling, and server-generated receipt. Then use Demo lab to request a correction and show the case returning to the citizen. Complete the certificate review and continue the original farm application.

Say explicitly: “This is our cooperating test portal, with real form operations and persistent backend records. Government services, rules, login and reviewer decisions are sandbox simulations. This version uses a deterministic adapter, not an LLM.”

## Why the handoff matters (20 seconds)
“The agent stops where the citizen must act. A real integration would keep authentication protected, require confirmation for consequential actions, and resume the same authorized session.”

## Practical deployment (30 seconds)
“Begin with one department and one verified workflow. Integrate with an approved API or a validated browser adapter. Add the language-model layer for understanding, while typed service definitions enforce allowed actions and required evidence.”

## Evidence (20 seconds)
Report actual automated and browser checks. Use the blank study worksheet to collect results before claiming time savings, completion improvements or usability outcomes. Mention the lack of a user study if it has not happened.

## Close (10 seconds)
“The goal is fewer steps for the citizen, with clearer control over every action.”

## Questions to prepare for
- Does this use an LLM? Not yet; deterministic workflow execution is implemented and labelled.
- Does it work on government sites? Not yet; the separately hosted sandbox proves the interaction contract. Official access and service testing are needed.
- What if the network drops? Saved server drafts persist; submissions can be checked before retrying. Concurrent duplicate protection needs transactional production storage.
- What happens to documents? Consent-gated sandbox storage; case deletion removes its uploaded files. Only fictional information is allowed for this demo.
- Does voice work on every phone? No. Browser support and language/accent quality must be tested; typing remains available.
